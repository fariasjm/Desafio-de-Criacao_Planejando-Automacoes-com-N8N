# 🎯 Desafio Criativo: Planejando Automações com N8N Usando Apenas Bons Prompts
Bem-vindo ao Desafio Criativo.
Nesta atividade, você seguirá algumas etapas simples que, ao final, irão ajudar a planejar uma automação em N8N a partir de um prompt claro e estruturado.

## 💡 Sobre o Exercício
Um bom prompt nasce de intenção clara, contexto e instruções específicas. Durante o desafio, você irá organizar suas ideias e transformá-las em comandos claros.

## 🧩 Construção Passo a Passo
Cada etapa adicionará uma nova peça ao seu prompt final. Ao concluir todas, você terá um prompt capaz de orientar uma IA a produzir exatamente o que você imaginou.

## 🚀 Como Resolver
Siga cada passo com atenção, registre suas respostas e, ao final, una todos os elementos para formar seu prompt final. Aproveite o processo criativo!


# 🧱 Passo 1: Defina a automação desejada
Nesta etapa, você vai descrever qual processo deseja automatizar e quem será beneficiado por ele.

## ✍️ O que fazer
Responda:

Qual tarefa repetitiva você deseja automatizar?
Quem utilizará ou será impactado pela automação?
Qual resultado final deve acontecer?

## 📋 Modelo para você adaptar
Copie o bloco abaixo no seu editor de texto e preencha os campos entre colchetes:

    text                                                                    Copiar
    Quero criar uma automação no N8N para [processo].

    Público ou responsável:
    [quem utilizará]

    Resultado esperado:
    [resultado desejado]

## ✨ Exemplo preenchido
    text                                                                      Copiar
    Quero criar uma automação no N8N para registrar automaticamente leads recebidos por formulário.

    Público ou responsável:
    Equipe comercial.

    Resultado esperado:
    Salvar os dados em uma planilha e enviar uma notificação para o time de vendas.


# 🧱 Passo 2: Adicione contexto e regras
Nesta etapa, você vai informar os sistemas envolvidos, as etapas do fluxo e as restrições importantes.

## ✍️ O que fazer
Responda:

  - Quais ferramentas ou serviços participam da automação?
  - Quais etapas devem acontecer em sequência?
  - Existe alguma regra, validação ou exceção?

## 📋 Modelo para você adaptar
Copie o bloco abaixo no seu editor de texto e preencha os campos entre colchetes:

    text                                                                        Copiar
    Ferramentas envolvidas:
    [lista de ferramentas]

    Fluxo desejado:
    1. [etapa 1]
    2. [etapa 2]
    3. [etapa 3]

    Regras importantes:
    [restrições, validações ou exceções]

## ✨ Exemplo preenchido
    text                                                                          Copiar
    Ferramentas envolvidas:
    Google Forms, Google Sheets e Gmail.

    Fluxo desejado:
    1. Receber uma nova resposta do formulário.
    2. Registrar os dados na planilha.
    3. Enviar um e-mail de confirmação.

    Regras importantes:
    Ignorar registros sem e-mail válido.


# 🧱 Passo 3: Monte o prompt final
Nesta etapa, você vai unir todas as peças construídas anteriormente em um único prompt completo.

## ✍️ O que fazer
Revise:

  - O objetivo da automação está claro?
  - As etapas estão em ordem?
  - As regras e restrições foram informadas?

## 📋 Modelo para você adaptar
Copie o bloco abaixo no seu editor de texto e preencha os campos entre colchetes:

    text                                                                            Copiar
    Atue como um especialista em N8N.

    Crie uma automação para [processo].

    Público:
    [público]

    Ferramentas envolvidas:
    [ferramentas]

    Fluxo:
    [etapas]

    Regras:
    [regras]

    Explique quais nós do N8N devem ser utilizados e a lógica de funcionamento do workflow.

## ✨ Exemplo preenchido
    text                                                                            Copiar
    Atue como um especialista em N8N.

    Crie uma automação para registrar leads recebidos por formulário.

    Público:
    Equipe comercial.

    Ferramentas envolvidas:
    Google Forms, Google Sheets e Gmail.

    Fluxo:
    Receber uma resposta, salvar os dados na planilha e enviar um e-mail de confirmação.

    Regras:
    Ignorar registros sem e-mail válido.

    Explique quais nós do N8N devem ser utilizados e a lógica de funcionamento do workflow.

## ☁️ Como entregar seu Desafio
Salve seu Prompt final em um arquivo

    text                                                                            Copiar
    .txt
ou

    text                                                                            Copiar
    .md
(no editor de sua preferência) e publique em um dos hosts aceitos pela DIO:

### Opção 1, Google Drive (mais simples):

- Faça upload do arquivo no seu Google Drive.
- Clique com o botão direito sobre o arquivo e escolha Compartilhar.
- Em Acesso geral, selecione Qualquer pessoa com o link.
- Copie o link e cole no campo de submissão da DIO.

### Opção 2, Git/GitHub (ótimo para praticar versionamento):

- Crie uma conta gratuita no GitHub, caso ainda não tenha.
- Crie um repositório público (ex:

      text                                                                  Copiar
      meus-desafios-criativos
).
- Adicione seu arquivo

      text                                                                    Copiar
      .md

ao repositório (pode ser pelo próprio site, em Add file > Upload files).
- Abra o arquivo no GitHub e copie o link da página (URL do navegador).
- Cole o link no campo de submissão da DIO.

Dica: o

    text                                                                  Copiar
    .md

no GitHub já é renderizado de forma bonita, sem precisar de nenhuma configuração extra.
